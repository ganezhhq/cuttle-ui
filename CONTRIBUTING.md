# Contributing

1. Install dependencies with `pnpm install` (Node 22 or newer).
2. Create a branch from `main`.
3. Run `pnpm lint`, `pnpm typecheck`, `pnpm test` and `pnpm build`.
4. Add a changeset with `pnpm changeset` if a published package changed.
5. Use [Conventional Commits](https://www.conventionalcommits.org/) for commit messages, for example `feat(core): add scroll lock`.

New components must meet the "done" checklist in the [roadmap](docs/roadmap/README.md).
